# DR Control Plane

[DR Control Plane by AppsCode](https://github.com/kubeops/dr-controlplane) - Common DC failover service for Kubernetes

## TL;DR;

```bash
$ helm repo add appscode https://charts.appscode.com/stable/
$ helm repo update
$ helm search repo appscode/dr-controlplane --version=0.1.0
$ helm upgrade -i dr-controlplane appscode/dr-controlplane -n dc-failover --create-namespace --version=0.1.0
```

## Introduction

This chart deploys a DR Control Plane on a [Kubernetes](http://kubernetes.io) cluster using the [Helm](https://helm.sh) package manager.

## Prerequisites

- Kubernetes 1.26+

## Installing the Chart

To install/upgrade the chart with the release name `dr-controlplane`:

```bash
$ helm upgrade -i dr-controlplane appscode/dr-controlplane -n dc-failover --create-namespace --version=0.1.0
```

The command deploys a DR Control Plane on the Kubernetes cluster in the default configuration. The [configuration](#configuration) section lists the parameters that can be configured during installation.

> **Tip**: List all releases using `helm list`

## Uninstalling the Chart

To uninstall the `dr-controlplane`:

```bash
$ helm uninstall dr-controlplane -n dc-failover
```

The command removes all the Kubernetes components associated with the chart and deletes the release.

Specify each parameter using the `--set key=value[,key=value]` argument to `helm upgrade -i`. For example:

```bash
$ helm upgrade -i dr-controlplane appscode/dr-controlplane -n dc-failover --create-namespace --version=0.1.0 --set namespace=dc-failover
```

Alternatively, a YAML file that specifies the values for the parameters can be provided while
installing the chart. For example:

```bash
$ helm upgrade -i dr-controlplane appscode/dr-controlplane -n dc-failover --create-namespace --version=0.1.0 --values values.yaml
```
